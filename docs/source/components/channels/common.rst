Shared Channel Helpers
======================

API Reference
-------------

.. rubric:: Source File

``src/simyuj/components/channels/_common.py``

This module contains shared construction and validation helpers used by
classical and quantum channel components. The helpers resolve propagation
delay, validate scalar inputs, and create the standard channel ingress and
egress ports.
