# Changelog

All notable changes to SimYuj will be documented in this file.

This project follows semantic versioning before 1.0 with the usual 0.x caveat:
public APIs may change before a 1.0 release.

## [0.1.0] - Unreleased

### Added

- Initial deterministic event-driven simulation engine.
- Quantum state storage, operations, measurement, sampling, and noise helpers.
- Component models for ports, channels, sources, detectors, and memories.
- Network, resource, control-plane, entanglement, metrics, runtime, and tracing
  subsystems.
- Sphinx documentation, examples, and test coverage for core simulator behavior.
- MIT license, citation metadata, and public project status documentation.
