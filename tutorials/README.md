# SimYuj tutorials

Work through the labs in order. Each notebook is a small lab: run a cell,
read the printout, then change one number and run it again.

1. `01_engine` - time, events, ordering, cancellation, RNG streams, and logs.
2. `02_tracing` - structured records for watching a run without changing it.
3. `03_runtime` - the binding step before events start.
4. `04_qstate` - state records, refs, gates, measurement, and noise.
5. `05_components` - ports, signals, sources, channels, detectors, and memories.
6. `06_network` - nodes, links, topology, routes, and runtime wires.
7. `07_metrics` - link and route scores for choosing paths.
8. `08_resources` - memory refs, reservations, availability, and route needs.
9. `09_entanglement` - pair records, registries, route queries, and expiry.
10. `10_control` - agents, timers, services, reports, and small workflows.
11. `11_capstone` - prepare one reserved entangled pair for a teleportation job.
12. `four_node_qkd` - run concurrent BB84 and E91 sessions on one four-node network.
